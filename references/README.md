# References

Sources behind the figures in the app. The Malaysia DOA guideline is the app's default;
a figure of the app's own is kept only where one of the sources below supports it.

Each paper here was downloaded from its publisher and read before the app cited it.
They are redistributed unchanged under the licence shown. If you reuse them, keep the
attribution and respect the licence — the two CC BY-NC-ND papers may not be used
commercially or modified.

## Looked for and not found

- **UC Davis Postharvest Center durian page** — the site refused the download, so its
  13–15°C recommendation is no longer cited in the app.
- **A source for Chanee maturing at about 90 days** — the app used to attribute this to
  *Scientific Reports*. That paper is about Monthong peduncles and does not say it. The
  figure has been removed; Chanee now follows the ITFNet table (100–115 days).
- **Clone-specific maturity days for Black Thorn, Tekka, IOI, Red Prawn, Red Flesh** — no
  published figure found. These clones use the DOA general figure.
